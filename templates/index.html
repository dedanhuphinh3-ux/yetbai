Cài đặt Gemini API Key

Nhập 1 lần, app nhớ mãi. Lấy key miễn phí tại AI Studio.

  1. Vào aistudio.google.com/apikey
  2. Đăng nhập Google → Create API key
  3. Copy key và paste vào đây ↓
